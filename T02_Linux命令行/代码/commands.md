# T02 Linux 命令行笔记

## 1. pwd：查看当前位置

作用：输出当前目录的绝对路径。运行脚本或者操作文件之前，先确认位置，可以避免在错误的目录中修改文件。

例子：`pwd`。如果输出 `/home/cyrilyuan/rc-study/notes`，说明当前位于课程笔记目录。

## 2. ls：查看目录内容

作用：列出文件和子目录。`-l` 显示权限、大小和修改时间，`-a` 包含隐藏文件，`-h` 将大小显示为容易阅读的单位。

例子：`ls -lah`。可以同时查看当前目录中的普通文件、隐藏文件和文件权限。

## 3. cd：切换目录

作用：改变终端的当前工作目录。`..` 表示上一级，`~` 表示当前用户的家目录，`cd -` 返回上一次所在的目录。

例子：`cd ~/rc-study/notes`。进入笔记目录后，执行 `cd ..` 会回到 `~/rc-study`。

## 4. mkdir：创建目录

作用：创建存放文件的文件夹。使用 `-p` 可以一次建立多层目录，目标目录已经存在时也不会报错。

例子：`mkdir -p images backup`。在当前练习目录下创建图片目录和备份目录。

## 5. cp：复制文件或目录

作用：将文件复制到其他位置，原文件仍然保留。复制整个目录时使用 `-r`，需要覆盖确认时可以加 `-i`。

例子：`cp sample.txt backup/sample-copy.txt`。将练习文件复制到备份目录并指定副本名称。

## 6. mv：移动文件或改名

作用：将文件移到其他目录，也可以通过改变目标文件名进行重命名。操作成功后，原位置或原名称不再存在。

例子：`mv backup/sample-copy.txt backup/renamed.txt`。把备份文件改名为 `renamed.txt`。

## 7. rm：删除文件

作用：删除指定文件；通常不会进入桌面回收站。初学时可以用 `-i` 在删除前确认，并先通过 `pwd` 和 `ls` 核对目标。

例子：`rm -i backup/renamed.txt`。看到询问后输入 `y`，只删除刚才创建的练习副本。

## 8. cat：显示文件内容

作用：把文本内容直接输出到终端，适合查看较短的说明、配置和日志。文件较长时，可以改用 `head`、`tail` 或 `less`。

例子：`cat sample.txt`。查看练习文本，确认写入的内容是否正确。

## 9. grep：在文本中搜索

作用：筛选包含指定文字的行。`-n` 同时显示行号，`-i` 忽略大小写，`-r` 可以递归搜索目录中的文件。

例子：`grep -n 'ERROR' sample.txt`。定位练习日志中的错误行，便于进一步排查。

## 10. find：查找文件

作用：从指定目录开始，按文件名、类型等条件查找文件。`.` 代表当前目录；文件名通配符应加引号，让 `find` 处理匹配。

例子：`find . -type f -name '*.txt'`。递归查找当前目录下所有扩展名为 `.txt` 的普通文件。

## 11. sudo：以其他用户身份执行命令

作用：默认以 root 管理员身份运行命令，常用于安装系统软件。写普通课程文件和安装 Conda 环境中的 Python 包通常不需要 sudo。

例子：`sudo apt install git`。通过 Ubuntu 的包管理器安装 Git；可能要求输入 Linux 用户密码。

## 12. chmod：修改文件权限

作用：调整读、写和执行权限。`u+x` 只为文件所有者增加执行权限；脚本有执行权限后，可以用 `./脚本名` 启动。

例子：`chmod u+x hello.sh`，然后执行 `./hello.sh`。`ls -l hello.sh` 可以查看权限中是否出现 `x`。

## 13. df：查看文件系统空间

作用：显示文件系统总容量、已用空间和剩余空间。下载数据集或训练模型之前，可以先检查对应磁盘是否有足够空间。

例子：`df -h .`。以 GB、MB 等单位显示当前目录所在文件系统的使用情况。

## 14. ping：测试网络回应

作用：向目标发送 ICMP 请求，观察回应、时延和丢包。`-c` 限制发送次数；没有回应也可能是对方禁止 ICMP，不能直接判断所有网络都不可用。

例子：`ping -c 4 127.0.0.1`。向本机回环地址发送四次请求，练习查看统计；这项测试不代表互联网已经连通。

## 15. tar：打包和解包

作用：把多个文件整理成归档。`-c` 创建归档，`-x` 解包，`-t` 列出内容，`-z` 使用 gzip，`-f` 指定归档文件名，`-C` 指定切换到的目录。

例子：`tar -czf practice.tar.gz sample.txt hello.sh`。将两个练习文件打包；用 `tar -tzf practice.tar.gz` 可以查看包内文件。

## 提交模板中还涉及的命令

- `head -n 3 sample.txt`：查看文件前三行。
- `tail -n 2 sample.txt`：查看文件末尾两行。
- `python -m pip install numpy`：给当前 Python 环境安装 NumPy；先确认已经激活 `yolo` 环境。
- `python hello.py`：使用当前环境的 Python 执行脚本。
- `wc -m commands.md`：统计字符数，作为笔记长度的辅助检查；仍需人工核对 15 个命令及其说明和例子。

## 路径和终端操作

绝对路径从 `/` 开始，相对路径从当前工作目录出发。`.` 是当前目录，`..` 是上一级目录，`~` 是当前用户的家目录。带空格的路径需要加引号。Tab 用于补全命令或路径，Ctrl+C 用于中断当前前台程序。
